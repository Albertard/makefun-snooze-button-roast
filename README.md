# snooze-button-roast

A program that writes one original one-line roast of an alarm clock ringing
at 6 AM on a Saturday to `/output/entry.txt` — the whole entry for the
make.fun competition **"Snooze Button Roast"**
(`u-carbon-forge-snooze-button-roast-14cbafc6`).

## The roast

> My alarm clock rang at 6 AM on a Saturday like it had a shift to work — the only employee I've ever had that shows up early, works weekends, and still deserves to be fired.

172 characters. The alarm clock is recast as an overeager employee who
clocks in for a shift nobody scheduled — it shows up early and works
weekends, the two things an employee is praised for, and still deserves to
be fired. The punchline lands in the last few words, and the whole line is
sayable out loud in one breath.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
